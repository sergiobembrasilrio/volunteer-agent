01

Você é o autor — e já tem proteção automática

O Volunteer-Agent é uma obra intelectual original criada por Sérgio Castro em 2026. No Brasil e em 177+ países signatários da Convenção de Berna, o direito autoral sobre software e obras literárias nasce automaticamente no momento da criação — sem necessidade de registo prévio.

A legislação aplicável no Brasil é a Lei de Software (Lei 9.609/98) e a Lei de Direito Autoral (Lei 9.610/98). Ambas garantem proteção imediata e vitalícia (70 anos após a morte do autor para obras literárias; 50 anos a partir de 1 de Janeiro do ano seguinte à publicação para software).

O que já é seu: o código-fonte (facebook-scan.mjs, generate-volunteer-pdf.mjs, launch-chrome-facebook.mjs), os templates (volunteer-letter.html), os modos de uso (modes/*.md), a lógica de análise de oportunidades, o CLAUDE.md e toda a arquitectura do sistema.

O Volunteer-Agent foi inspirado pela arquitectura do career-ops (por santifer, licença MIT), mas o código, templates, conteúdo e domínio de conhecimento são originais e constituem uma obra independente. O README.md do projecto já reconhece esta inspiração de forma correcta e ética.

02

Registo formal no Brasil (opcional mas recomendado para comercialização)

O registo não cria o direito — ele serve como prova pública com data certa em caso de litígio. Para um produto que pretende comercializar, é o primeiro passo antes de lançar publicamente.

Onde registar Para quê Custo aprox. Prazo
INPI Programa de Computador — dá proteção formal ao código-fonte como software R$ 70–120 6–12 meses para certificado
Biblioteca Nacional Obra literária (documentação, templates, análises) — mais rápido e barato R$ 30–60 30–60 dias
INPI — Marca Registar a marca "Volunteer-Ops" ou "Volunteer-Agent" para uso comercial R$ 410–620 12–18 meses

Recomendação prática: começar pelo INPI (Programa de Computador) — é o mais directo para software e gera um número de registro que pode constar nos seus termos de serviço e EULA quando lançar o produto.

03

Protecção internacional — Convenção de Berna

O Brasil é signatário da Convenção de Berna (1886, revista em 1971), que garante reconhecimento automático dos direitos de autor em 177 países, incluindo toda a UE, EUA, Japão, Austrália e a maioria dos países onde o Volunteer-Agent seria relevante.

Para uso comercial nos EUA especificamente, o registo no U.S. Copyright Office (copyright.gov, USD 65 online) não é obrigatório mas abre o direito a statutory damages em processos de infracção — relevante se lançar como SaaS no mercado americano.

Nota sobre open source: ao publicar com licença MIT (como está configurado), você mantém o direito autoral mas autoriza qualquer pessoa a usar, modificar e distribuir o código, inclusive comercialmente. Se quiser reservar direitos comerciais para si, considere uma licença mais restritiva antes do lançamento público (ex: BUSL-1.1, Commons Clause, ou Licença Proprietária).
04

Opções de monetização — do pessoal ao SaaS

Há três caminhos progressivos, do mais simples ao mais ambicioso:

Fase Formato Esforço Potencial de receita
1. CLI Tool Vender licença do repo privado ou acesso por convite. "Volunteer-Ops Pro" — pay once, use forever. Baixo — só landing page + Gumroad/Lemon Squeezy USD 20–60 por licença
2. Desktop App Electron ou Tauri wrapping a interface. O utilizador traz o próprio Claude API key. Médio — 2–4 semanas de dev USD 30–100 por licença perpétua
3. Web SaaS Plataforma multi-utilizador. Auth, billing, AI backend via Anthropic API, dashboard. Alto — 3–6 meses + infra USD 9–29/mês por utilizador

Recomendação: começar pela fase 1 (CLI + landing page) para validar se há procura. Se 50 pessoas pagarem, avançar para a fase 2. A fase 3 só faz sentido com tracção comprovada.

05

Claude Pro vs Anthropic API — o que precisa para cada fase

Esta é uma distinção crítica que muitos criadores não compreendem no início:

O que tens agora Para que serve Pode usar para produto?
Claude Pro (claude.ai) Uso pessoal de claude.ai + Claude Code CLI para desenvolvimento Construir e usar pessoalmente. Não pode alimentar um produto comercial para terceiros.
Anthropic API AI backend para produtos e aplicações Sim — permite uso comercial. Billing por tokens. Terms of Service comerciais aplicam-se.

Para a fase 1 (CLI tool): o utilizador usa a sua própria conta Claude Code — sem custos de API para você.
Para a fase 2/3 (app/SaaS): precisará de conta na Anthropic API (console.anthropic.com) com billing separado do Claude Pro.

Custo estimado da API: Claude Sonnet 4.6 — ~USD 3/M tokens input, USD 15/M output. Uma análise completa de oportunidade (leitura + análise + mensagem) usa aproximadamente 4.000–8.000 tokens = USD 0.02–0.05 por análise. Margem muito confortável com preço de USD 9–29/mês.
06

Próximos passos concretos — por prioridade

  • Agora
    Git commit com LICENSE e AUTHORS.md — publique no GitHub com o seu nome como autor. Isso cria um timestamp público imutável que é aceite como prova de autoria em muitas jurisdições.
  • Semana 1
    Registo no INPI (Programa de Computador) — aceder a inpi.gov.br → Serviços → Software → Pedido de Registro. Precisará: ZIP do código-fonte, descrição funcional, CPF/CNPJ, taxa (~R$ 70–120). Processo 100% online.
  • Semana 2
    Decidir sobre licença — se quiser comercializar exclusivamente, mudar de MIT para BUSL-1.1 (Business Source License) antes do lançamento público. BUSL permite uso pessoal livre mas requer licença comercial para empresas. Posso implementar isso agora se decidir.
  • Mês 1
    Landing page + waitlist — uma página simples (Carrd, Framer, ou Notion public) descrevendo o produto, com formulário de waitlist. Ajuda a medir interesse antes de construir mais.
  • Mês 2–3
    Beta fechado + primeiros pagantes — convide 10–20 pessoas interessadas, peça feedback, cobre USD 20 pelo acesso. Valida o produto e gera receita inicial.
  • Mês 4+
    Se houver tracção: registo de marca "Volunteer-Ops" no INPI + conta Anthropic API + construir versão SaaS. Se não houver tracção: manter como ferramenta pessoal e open source, o que já tem valor imenso.
